# brew-release-notes

Homebrew 週次チェックが出力したレポート（`brew-check-YYYY-MM-DD.md`）を Claude が読み、更新可能なパッケージのリリースノートを調べて、セキュリティ修正・破壊的変更をまとめた `release-notes-YYYY-MM-DD.md` をレポートと同じフォルダに書き出すスキルです。

手順の本体は [SKILL.md](SKILL.md) にあります。

- Claude は `brew upgrade` などパッケージを変更する操作をおこないません。更新は手動でおこなってください
- 既存のレポート・ログは読むだけで、書き込むのは `release-notes-*.md` だけです

## 前提条件

- HomebrewPackageChecker を導入し、レポートが出力されていること
  - launchd 版：[Tools/macOS/launchd/HomebrewPackageChecker](../../../Tools/macOS/launchd/HomebrewPackageChecker/README.md)（出力先は配置したフォルダ内の `reports/`）
  - ショートカット.app版：[Tools/macOS/Shortcuts/HomebrewPackageChecker](../../../Tools/macOS/Shortcuts/HomebrewPackageChecker/README.md)（出力先 `~/brew-check`）
- Claude デスクトップアプリ（Cowork）を使い、Mac に接続できること

## 1. スキルを登録する

Claude アプリで「カスタマイズ」→「スキル」→「追加」→「スキルをアップロード」を開き、[SKILL.md](SKILL.md) をスキルとして登録します。

## 2. レポートフォルダを紐づける

レポートの場所はパスを決め打ちせず、Cowork セッションまたはプロジェクトに紐づけられたフォルダから探します。次のどちらかで、レポートが入っているフォルダを紐づけてください。

- プロジェクトを作成し、プロジェクトの「フォルダ」にレポートフォルダを接続する（定期実行する場合はこちらを推奨）
- Cowork セッションに「フォルダを追加」でレポートフォルダを追加する

紐づけられたフォルダに `brew-check-*.md` が見つからない場合、Claude は処理を中止し、フォルダの紐づけを依頼してきます。Claude が勝手にフォルダを追加することはありません。

## 3. スケジュール済みタスクを作成する

手順 2 のプロジェクト（またはセッション）で、次のように依頼します。

```
brew-release-notes スキルの「B. スケジュール済みタスクの作成」に従って、タスクを登録してください。
```

Claude はレポートフォルダを確認したうえで、次の内容でタスクを登録します。

| 項目 | 内容 |
| --- | --- |
| 名前 | Homebrew 更新内容まとめ |
| 実行 | 毎週月曜 10:00（`CRON_TZ=Asia/Tokyo 0 10 * * 1`）。週次チェック（月曜 9:00）の後 |
| ローカルデバイス | 必要（Mac のフォルダを読むため） |
| フォルダ | レポートフォルダを含む、紐づけ済みのフォルダ |

登録後、実行時刻・紐づけたフォルダ・承認の設定（自動承認か、毎回確認か）が報告されます。時刻を変えたい場合は、依頼文で指定してください。

## 手動で実行する

定期実行を待たずに処理したい場合は、手順 2 のプロジェクト（またはセッション）で次のように依頼します。

```
brew-release-notes スキルの「A. 実行」に従って、最新のレポートを処理してください。
```

- 最新レポートが 8 日以上前の場合は、週次チェックが止まっている可能性として報告し、終了します
- 同じ日付の `release-notes-*.md` が既にある場合は、処理済みとして終了します
- 更新可能なパッケージがない場合は、ファイルを作らず「更新なし」と報告します

## 出力

レポートフォルダに `release-notes-<レポートの日付>.md` が書き出されます。パッケージごとに次の 4 段階で分類され、セキュリティ修正があるものが先頭にまとめられます。

| 分類 | 意味 |
| --- | --- |
| 🔴 | セキュリティ修正あり |
| 🟡 | 破壊的変更・要注意あり（セキュリティ修正なし） |
| 🟢 | 通常の更新 |
| ⚪ | リリースノートが見つからない |

各パッケージの「更新の目安」は参考です。内容を確認してから `brew upgrade <name>` で個別に更新してください。
