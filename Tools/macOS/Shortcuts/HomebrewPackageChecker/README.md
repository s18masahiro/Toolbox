# HomebrewPackageChecker

Homebrew の `update` → `outdated` → `doctor` をまとめて実行し、結果を Markdown レポートに保存して通知で知らせる macOS ショートカットです。

## 利用条件

1. ターミナルからコマンド実行できるなど、基礎知識があること
   1. homebrew 本体のインストールやパッケージのアップデートを手動実行するために必要

## 動作

1. `brew update` でパッケージ情報を更新
2. `brew outdated --formula` / `--cask` で更新可能なパッケージを一覧化
3. `brew doctor` で環境を診断し、`Warning:` の件数を数える
4. `brew-check-YYYY-MM-DD.md` にレポートを保存し、`brew-check.log` に件数を1行追記
5. 結果を通知「Homebrew パッケージ診断」で表示
   - 更新・警告・失敗のいずれかがあれば、レポートを自動で開く

`brew upgrade` は実行しません（確認のみ）。90日より古いレポートは自動で削除されます。

### 通知メッセージ

| 状態 | 通知 |
|---|---|
| `brew update` 失敗 | Homebrew の更新確認に失敗しました。レポートを開きます |
| 更新あり + 警告あり | 更新できるパッケージと、診断での警告があります。レポートを開きます |
| 更新あり | 更新できるパッケージがあります。レポートを開きます |
| 警告あり | 診断で警告が見つかりました。レポートを開きます |
| 問題なし | すべて最新で、問題は見つかりませんでした |

## 必要なもの、事前準備

- macOS（ショートカット.app）
- [Homebrew](https://brew.sh/)（`/opt/homebrew/bin` または `/usr/local/bin`）
- ショートカット.app の「設定 → 詳細 → スクリプトの実行を許可」を有効にする

## インストール

`HomebrewPackageChecker.shortcut` をダブルクリックしてショートカットに追加します。

## 定期実行するようにする（macOS 26 以降）

ショートカット.app のオートメーションで、次のように設定すれば「毎週月曜 10:00」に、このショートカットを自動実行できます。頻度は変えたい場合は時刻を調整してください。

1. ショートカット.app のサイドバーで「オートメーション」を選ぶ
2. 「新規オートメーション」（`+`）をクリックし、トリガに「時刻」を選ぶ
3. 時刻を `10:00`、繰り返しを「毎週」にして「月曜日」だけを選ぶ
4. 実行方法を「すぐに実行」にする（「実行前に確認」だと確認待ちで止まる）
5. 実行するショートカットに `HomebrewPackageChecker` を選んで完了

- Mac がスリープ中・ログアウト中の時刻には実行されません
- 結果は通常どおり通知とレポートで確認できます

## 設定

### 保存先

先頭の「リスト」アクションの値が、シェルスクリプトに引数として渡されます。

| 項目 | 引数 | 既定値 |
|---|---|---|
| 1行目 | レポートの保存先フォルダ | `~/brew-check` |
| 2行目 | ログの保存先フォルダ | `~/brew-check` |

空欄にするとスクリプト内の既定値（`~/brew-check`、ログはレポートと同じ場所）が使われます。

※ `~/brew-check` は、アカウントのホームディレクトリ直下（ミュージックや書類といったフォルダがあるところ）に「brew-check」をつくる、という値です。

### スクリプト内の設定

「シェルスクリプトを実行」アクション冒頭の変数で変更できます。

| 変数 | 既定値 | 内容 |
|---|---|---|
| `DEFAULT_DIR` | `$HOME/brew-check` | 引数がないときの保存先 |
| `KEEP_DAYS` | `90` | これより古いレポートを削除 |
| `OPEN_REPORT` | `1` | `1`: 更新・警告・失敗時にレポートを開く / `0`: 開かない |

## 出力例

```
~/brew-check/
├── brew-check-2026-10-23.md   # レポート（概要表・更新可能な formula / cask・brew doctor の出力）
└── brew-check.log             # [2026-10-23 09:00:00] 更新 3 件（formula 2 / cask 1）、doctor 警告 0 件 → ...
```

更新する場合はレポート末尾の案内どおり `brew upgrade`（cask も含めるなら `brew upgrade --greedy`）を手動で実行してください。
