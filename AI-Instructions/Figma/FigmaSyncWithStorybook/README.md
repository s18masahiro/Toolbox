# Figma Sync with Storybook

Storybook のコンポーネントを、Figma MCP を使って Figma のコンポーネント・変数に同期するための AI 向け指示書です。

[FIGMA-SYNC.md](FIGMA-SYNC.md) をリポジトリに置いておくと、AI に「Storybook と Figma を同期して」と頼むだけで、毎回同じルール（命名、props とバリアントの対応、変数の紐付け、同期履歴の記録）で作業してくれます。

## 前提条件

次の 4 つは必須です。

- **Storybook を導入済みであること**
  - 同期対象はストーリーファイル（`*.stories.tsx` など）で決まります。ストーリーがないコンポーネントは同期されません
  - ストーリーの `title` は `Components/〇〇` の形式を想定しています（Figma のコンポーネント名に使います）。形式が違う場合は FIGMA-SYNC.md の「3.1 コンポーネント名」を書き換えてください
- **Figma の書き込み先ファイルの編集権限があること**
  - Figma MCP で書き込むには、そのファイルを編集できるシート（Full シートなど）が必要です
- **MCP に対応した AI エージェントを使うこと**
  - Claude Code、Codex、Cursor など、リモート MCP サーバーに接続できるもの
- **Figma のスキル（`/figma-use`・`/figma-generate-library`）を使えること**
  - FIGMA-SYNC.md は書き込みの前にこの 2 つのスキルを読み込む前提です。Claude Code では Figma プラグインに入っています

次の 2 つはあると便利です（なくても同期はできます）。

- Storybook の画面のスクリーンショットを撮る手段（Playwright など）。Figma とコードの見た目を比べるのに使います
- デザイントークンを CSS 変数などにまとめていること。まとまっていれば、変数を同期する元にできます

> **Figma のプランについて**：Starter プランでは、MCP のツールを呼び出せる回数の上限が厳しく、変数コレクションのモードも 1 つしか作れません。FIGMA-SYNC.md にはこの制限への対処も書いてありますが、継続して使うなら Professional 以上のプランをおすすめします。

## セットアップ手順

### 1. Figma MCP を接続する

次の公式ページを参照して、利用中の開発環境に合わせてセットアップをおこなってください。

[Figma MCPカタログ](https://www.figma.com/ja-jp/mcp-catalog/)

接続できたかどうかは、AI に「Figma MCP で whoami を実行して」と頼むと確かめられます。自分の Figma アカウントが返ってくれば接続できています。

### 2. FIGMA-SYNC.md をリポジトリに置く

[FIGMA-SYNC.md](FIGMA-SYNC.md) を、同期したいプロジェクトのリポジトリのルートにコピーします。

### 3. AGENTS.md / CLAUDE.md から参照させる

AI が FIGMA-SYNC.md を自動で読むように、普段 AI が読み込む指示ファイルに参照を書き足します。Claude Code は `CLAUDE.md` を、Codex や Cursor などは `AGENTS.md` を読みます。この作業は AI に任せられます。プロジェクトのリポジトリで次のように頼んでください。

```text
FIGMA-SYNC.md をリポジトリのルートに置きました。
「Storybook と Figma を同期して」と頼まれたときに FIGMA-SYNC.md を読んで従うよう、
AGENTS.md（または CLAUDE.md）に参照を追記してください。ファイルがなければ作成してください。
```

AI が書き足す内容は、たとえば次のようになります。

```md
## Figma 同期

Storybook と Figma の同期を頼まれたら、作業を始める前に [FIGMA-SYNC.md](FIGMA-SYNC.md) を読み、その設定とルールに従うこと。
```

### 4. `（要入力）` の箇所を埋める

FIGMA-SYNC.md の `（要入力）` の箇所を、プロジェクトに合わせて書き換えます。

| セクション         | 書く内容                                                                      |
| ------------------ | ----------------------------------------------------------------------------- |
| 1. 同期先          | Figma ファイルの URL と fileKey、書き込み先ページ、変数の管理場所、Figma のプラン |
| 2. 同期対象        | ストーリーファイルの場所のパターン、各コンポーネントを同期するかどうか          |
| 3.3 変数・スタイル | 変数の元にする CSS ファイルと変数コレクションの対応、モード、フォント          |
| 4. 同期の進め方    | Storybook を起動してスクリーンショットを撮る方法                              |
| 5. 禁止事項        | サンプルテキストに使ってはいけない機密情報の場所                              |

ほとんどの項目はリポジトリを読めばわかるので、AI に下書きを頼むと早く済みます。

```text
リポジトリの構成、ストーリーファイル、スタイル定義を読んで、FIGMA-SYNC.md の（要入力）を埋める案を作ってください。
Figma ファイルの URL は https://www.figma.com/design/xxxx/xxxx です。
わからない項目は推測で埋めずに、質問してください。
```

AI が作った案は自分で確認してから確定してください。特に「2. 同期対象」の対象外の判断と「5. 禁止事項」は、実際の運用に合っているか必ず見直してください。

「6. 同期履歴」と「7. 未決事項・追加要件メモ」は空のままで構いません。同期するたびに AI が書き込みます。

## 使い方

セットアップが終わったら、AI に次のように頼みます。

```text
Storybook と Figma を同期して
```

AI はまず同期計画（新規作成・更新・変更なしの分類）を提示し、こちらが承認してから Figma に書き込みます。終わると結果を報告し、FIGMA-SYNC.md の「6. 同期履歴」を更新します。
